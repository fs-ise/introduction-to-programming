# Lucide icons

These icons are vendored from [Lucide](https://lucide.dev/) version 0.468.0:

- `lightbulb.svg`
- `message-circle-question.svg`
- `triangle-alert.svg`
- `clock.svg`
- `settings.svg`

The SVG paths are from the upstream Lucide files. The `stroke` color was changed
to match each callout's semantic color. Each `.pdf` is a vector conversion of
the corresponding SVG for use in printable notes. The icons are licensed under
the terms included in [`LICENSE`](LICENSE); the clock icon is derived from
Feather and covered by its MIT license as noted there.
